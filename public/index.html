검사실 사용 안내

1. 검사 엔진 실행

검사앱_v4_실행.command를 더블클릭하세요. 준비 완료 후 사진을 검사합니다. 실행창은 켜두세요. 위치 표시 업데이트 안내가 보이면 기존 엔진 실행창을 종료한 다음 다시 실행하세요.

2. 사진 선택

기판 하나가 선명한 JPG·PNG·WEBP 사진을 올리세요. 20MB·2,400만 화소 이하, 대기 최대 10장입니다. 크롭 사진은 입력 옵션을 선택하세요.

3. 판정과 영역 확인

불량 의심은 기준 초과, 결함 미검출은 기준 이하입니다. 주황 상자는 보정 기준을 넘은 의심 위치, 파란 상자는 상대 이상도가 높은 우선 확인 위치입니다. 기준 이하 사진에도 확인 위치가 표시될 수 있으며 전체 판정은 바뀌지 않습니다. 위치 표시를 끄면 번호 상자만 사라지고 히트맵 색상은 그대로 유지됩니다. 색과 번호만으로 결함을 확정하지 않습니다.

4. v4 인터랙션

시작 화면의 3D 기판은 드래그로 회전하고 휠로 확대합니다. 분해 보기로 부품을 펼칠 수 있습니다. 검사 결과의 드래그 비교는 원본과 히트맵 사이를 직접 움직여 확인합니다. 확대 렌즈는 사진의 디테일을 2배로 보여줍니다. 상단 모션 버튼으로 연출을 멈출 수 있습니다.

현재 큰 파란 격자 기판만 검사합니다. 지원하지 않는 기판과 검출 실패는 재검토가 필요합니다.

사진은 이 컴퓨터의 엔진에서 처리합니다. 실제 검사에는 기존 Python 환경과 모델 파일이 필요합니다. 첫 화면은 검사 공간의 컨셉 그래픽이며 AI 판정 결과가 아닙니다.

카메라 연속 검사 성능은 아직 검증되지 않았습니다. 시작 화면에 돌아가면 카메라가 종료됩니다.
